From CurseForge (https://www.curseforge.com/minecraft/texture-packs/tfc-vexxed-visuals-anvil-helper):

I really enjoy the updated anvil UI in Vexxed Visuals, but was surprised to see no one's made an anvil helper in the same style, so I made one! Basically wombo-combo'd TFC Anvil Helper by absolutespiceball with the anvil UI texture in Vexxed Visuals by Vexxel, alongside some minor edits to make it suit and be more coherent. 

Personally added black highlights to the small text to increase visibility and changed the little arrow indicators back to the default TFC bright green and red from the white and blue in Vexxed Visuals. Aside from that, all credits go to the original creators of the textures, as well as the team behind TerraFirmaCraft!

05.26: Update includes coloured pixel corrections to positions 3, 6, 19, and 22 done by VizzyDizzy from their TFC Anvil Helper Patched. Massive thanks to them for finding and correcting the issue!
